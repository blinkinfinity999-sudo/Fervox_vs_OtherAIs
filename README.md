# 🚀 Fervox AI vs. The Giants (Landing Page & Pitch Deck)

An ultra-optimized, high-performance, developer-focused landing page designed to rank for competitive SEO terms and demonstrate why **Fervox AI** outpaces corporate AI platforms like ChatGPT, Gemini, and Claude for power users. 

This repository includes a production-ready, highly semantic HTML framework, an interactive presentation viewer components, a premium cyberpunk-inspired dark theme stylesheet, and the standalone raw presentation pitch assets.

## ✨ Features

* **⚡ SEO & Featured Snippet Optimized:** Built with semantic headers and structural bold statements specifically targeted to trigger Google's AI Overview and Featured Snippet summary blocks.
* **📦 JSON-LD Schema Integration:** Pre-configured structured data schema embedded into the head to feed Google's search crawlers precise contextual product review data instantly.
* **🎨 Cyberpunk Dark UI Theme:** A professional dark mode (`style.css`) built using deep space hues, crisp modern borders, fluid typography gradients, and subtle glow elements.
* **📊 Interactive Pitch Slide Component:** A modular, client-side, zero-dependency slider (`script.js`) allowing users to click through the Fervox pitch deck directly inside the browser viewport.
* **📥 Standalone Deck Pipeline:** Linked directly to provide instant programmatic downloads for the physical standalone `.pptx` file.
* **⚖️ Airtight Legal Architecture:** Includes an industry-standard trademark fair-use disclaimer footer to provide complete protection against corporate trade libel or defamation reports.

## 🚀 Getting Started

### 1. Local Setup
Clone this repository directly into your local machine and open the entry node:
```bash
git clone https://github.com
cd fervox-vs-giants
open index.html
```

### 2. Deployment
Because this site uses a stripped, client-side-only runtime layer, you can drop it onto any modern global edge network in one click:
* **Vercel:** Run `vercel` or link your repository path directly to your project profile dashboard.
* **GitHub Pages:** Rename your master node branch target or configure the static page builder engine via repository settings.

## 🛠️ Customizing the Content

* **To add more slides:** Simply append a new `div` with the class `slide` into the `.slide-deck` container inside `index.html`. The `script.js` file automatically recalculates bounds and tracks slide index increments.
* **To alter branding colors:** Edit the global hex map configurations specified inside the root element wrapper block within `style.css`:
```css
:root {
    --bg-main: #0B0F19;
    --accent: #3B82F6;
    --success: #10B981;
}
```

## 🔍 Forcing Google to Index This Page

Once you launch your live URL (e.g., `fervoxai.vercel.app/vs/chatgpt`), do not wait for standard crawl bots to find it:
1. Log into your **Google Search Console** dashboard.
2. Select your root application property mapping.
3. Paste the comparison URL into the top search investigation box.
4. Click **"Request Indexing"** to force immediate system crawling.
